ALGORITHM WALKTHROUGH

From records to ranked matches

02SortDistance, priority or ID

03GreedyTry the top-ranked donors

04BacktrackTry alternatives if needed
A

Compatibility scan

Check each record against the red-cell donor compatibility table, then remove unavailable donors.

O(N)
B

Priority sort

Order eligible donors by the selected rule. The first ranked records become the greedy attempt.

O(M log M)
C

Alternative search

If the greedy set breaks the one-per-location rule, recursively try other ranked combinations.

O(2^M) worst case
